# Σιδηρόδρομοι Ευρώπης

Παιχνίδι για παρέα: το ταμπλό παίζει στην τηλεόραση, ο καθένας παίζει από το κινητό του.

## Πώς παίζεται

1. Άνοιξε τη διεύθυνση του site στην τηλεόραση και πάτα **📺 Ταμπλό στην τηλεόραση**.
   Εμφανίζεται τετραψήφιος κωδικός.
2. Ο καθένας ανοίγει το ίδιο site στο κινητό του, πατά **📱 Είμαι παίκτης**,
   και βάζει τον κωδικό, το όνομά του και έναν προσωπικό κωδικό.
   Ο προσωπικός κωδικός χρειάζεται μόνο αν κλείσει το κινητό και θέλει να ξαναμπεί στη θέση του.
3. Όταν μπουν όλοι, πατάς **Ξεκίνα** στην τηλεόραση.

Στη σειρά σου: είτε τραβάς **δύο κάρτες** (από τις φανερές ή από την τράπουλα),
είτε **διεκδικείς μία διαδρομή** πατώντας την στον χάρτη.
Οι διαδρομές που μπορείς να πάρεις τώρα φωτίζονται με πράσινο περίγραμμα.

Παίζει η απλοποιημένη έκδοση: χωρίς τούνελ, σταθμούς και κάρτες αποστολών.
Τα πορθμεία ισχύουν κανονικά (θέλουν ατμομηχανές).

## Ανέβασμα στο Render

1. Ανέβασε αυτόν τον φάκελο σε ένα repo στο GitHub.
2. Στο [render.com](https://render.com) → **Get started** → σύνδεση με GitHub.
3. **New +** → **Web Service** → διάλεξε το repo.
4. Ρυθμίσεις: Build Command `npm install`, Start Command `node server.js`, Instance Type **Free**.
5. **Create Web Service**. Σε λίγα λεπτά παίρνεις διεύθυνση της μορφής
   `https://κάτι.onrender.com` — αυτή ανοίγεις σε τηλεόραση και κινητά.

Το δωρεάν επίπεδο κοιμάται μετά από 15 λεπτά χωρίς κίνηση· η πρώτη σελίδα μετά τον ύπνο
αργεί περίπου ένα λεπτό να φορτώσει. Άνοιξε πρώτα την τηλεόραση και μετά τα κινητά.

## Δομή

| Αρχείο | Τι κάνει |
|---|---|
| `server.js` | Σερβίρει τις σελίδες, κρατά τα δωμάτια στη μνήμη, μοιράζει τις αλλαγές |
| `public/engine.js` | Οι κανόνες — καθαρή λογική, τρέχει και στον server και στον browser |
| `public/board.js` | Η ζωγραφική του χάρτη, κοινή σε τηλεόραση και κινητά |
| `public/tv.html` | Η οθόνη της τηλεόρασης |
| `public/play.html` | Η οθόνη του παίκτη |
| `public/routes.json` | Το δίκτυο: πόλεις, μήκη, χρώματα, πορθμεία |
| `test-engine.js` | 35 έλεγχοι κανόνων — `npm test` |

Τα παιχνίδια ζουν στη μνήμη του server. Αν ο server ξεκινήσει από την αρχή, χάνονται.
