# Ticket to Ride – Ευρώπη

Ψηφιακή έκδοση του Ticket to Ride Europe για παιχνίδι στο σπίτι:
το board παίζει στην τηλεόραση και κάθε παίκτης παίζει από το κινητό του.
Οι κανόνες είναι στο [RULES.md](RULES.md).

## Πώς παίζεται

1. **Admin** (`/admin`): μπαίνεις με τον κωδικό admin και πατάς «Νέο παιχνίδι». Βγαίνει ένας τετραψήφιος κωδικός.
2. **Τηλεόραση** (`/tv`): ανοίγεις τη σελίδα στον browser της τηλεόρασης και γράφεις τον κωδικό
   (ή πατάς «Άνοιγμα στην τηλεόραση» από το admin). Δείχνει QR code για τους παίκτες.
3. **Παίκτες** (`/`): σκανάρουν το QR ή ανοίγουν τη σελίδα και γράφουν κωδικό, όνομα, PIN 4 ψηφίων και χρώμα.
   Με το ίδιο όνομα και PIN ξαναμπαίνουν αν κλείσει το κινητό.
4. Ο admin πατάει «Έναρξη». Κάθε παίκτης κρατάει προορισμούς και μετά παίζει στη σειρά του από το κινητό:
   - πατάει ανοιχτή κάρτα ή την τράπουλα για να τραβήξει κάρτες,
   - πατάει μια πόλη ή διαδρομή στο board για να την πάρει ή να χτίσει σταθμό,
   - πατάει «Προορ.» για νέες κάρτες προορισμού.
5. Ο admin μπορεί να κάνει **Restart** (νέο μοίρασμα, ίδιοι παίκτες), **Πίσω στην αναμονή**
   (για να μπει κάποιος ακόμα), **Παράλειψη σειράς** (αν κάποιος λείπει) ή **Κλείσιμο**.

## Τοπικά στον υπολογιστή

Χρειάζεται [Node.js](https://nodejs.org) 20 ή νεότερο.

```bash
npm install
```

```bash
npm start
```

Άνοιξε http://localhost:3000/admin (κωδικός admin τοπικά: `admin`, αν δεν έχεις ορίσει `ADMIN_PASSWORD`).
Από κινητά στο ίδιο WiFi άνοιξε `http://<IP του υπολογιστή>:3000`.

Τεστ κανόνων και server:

```bash
npm test
```

Ρομπότ παίκτες, για να δεις το παιχνίδι στην τηλεόραση χωρίς κόσμο (μετά πάτα «Έναρξη» στο admin):

```bash
node tools/bot.js --code 1234 --join 3
```

## Ανέβασμα στο Render

1. Ανέβασε τον φάκελο σε ένα repository στο GitHub (το `.gitignore` κρατάει έξω τη φωτογραφία του αρχικού board και τα `node_modules`).
2. Στο [Render](https://render.com): **New → Blueprint** και διάλεξε το repository. Το `render.yaml` ρυθμίζει τα πάντα.
3. Όταν σου ζητήσει `ADMIN_PASSWORD`, βάλε τον κωδικό που θα χρησιμοποιεί ο admin.
4. Η διεύθυνση θα είναι κάτι σαν `https://ticket-to-ride-xxxx.onrender.com`.

Στο δωρεάν πλάνο του Render ο server «κοιμάται» όταν δεν τον χρησιμοποιεί κανείς. Το πρώτο άνοιγμα αργεί
περίπου ένα λεπτό. Όσο είναι ανοιχτή η τηλεόραση ή κάποιο κινητό, οι σελίδες τον κρατάνε ξύπνιο.
Αν ο server ξεκινήσει από την αρχή (π.χ. μετά από νέο deploy), τα ανοιχτά παιχνίδια χάνονται.

## Δομή

| Αρχείο | Τι κάνει |
|---|---|
| `server.js` | Web server (Express + Socket.IO): σελίδες, σύνδεση παικτών/τηλεόρασης/admin, QR code. |
| `server/game.js` | Οι κανόνες: κάθε κίνηση ελέγχεται εδώ, και εδώ γίνεται η τελική βαθμολογία. |
| `server/rooms.js` | Παιχνίδια με τετραψήφιο κωδικό, παίκτες με όνομα/PIN, αποθήκευση σε `data/rooms.json`. |
| `public/js/map-data.js` | Πόλεις, 101 διαδρομές, 46 κάρτες προορισμού (κοινό για server και browser). |
| `public/js/board.js` | Σχεδιάζει το board σε SVG. |
| `public/js/payments.js` | Με ποιες κάρτες πληρώνεται μια διαδρομή, σταθμός ή σήραγγα. |
| `public/index.html`, `play.html`, `tv.html`, `admin.html` | Είσοδος, κινητό, τηλεόραση, admin. |
| `public/data/land.json` | Ακτές και σύνορα (Natural Earth), προσαρμοσμένα στις θέσεις των πόλεων. |
| `public/board.html` | Σελίδα δοκιμής του board. Με `/board.html?check` βάζει κόκκινους κύκλους σε ό,τι επικαλύπτεται (βαγόνια, ονόματα, πόλεις). |
| `tools/build-land.js` | Ξαναφτιάχνει το `land.json` αν αλλάξουν οι θέσεις των πόλεων: `node tools/build-land.js`. |
| `tools/bot.js` | Ρομπότ παίκτες για δοκιμές. |
| `test/` | Αυτόματα τεστ (`npm test`). |
